# 研序 Yanxu · 本地科研工作台

> 面向学生和算法工程师的本地科研自动化工作台：论文雷达 → 公式/图/代码精读 → 审批驱动的实验闭环 → 可追溯的离线 HTML 汇报。

研序把「研究问题 → 找到证据 → 理解方法 → 验证假设 → 形成认识」串成一条可审计的链路。
资料保存在本机，实验先审批后执行，任何结论都能沿证据链回到原始日志或论文原文。

## 核心能力

| 模块 | 说明 |
| --- | --- |
| 论文雷达 | arXiv 检索、Crossref DOI 核对、PDF 导入与逐页图像；推荐区分「摘要级判断」与「全文已读」 |
| 精读工作台 | 公式分步讲解（符号表、维度、逐项高亮、原文页码对照）、图片区域放大解读、代码行级数学对应 |
| 实验工作台 | 预注册、人工审批、受控批次、GPU/时长预算、停滞熔断、smoke 三关、最终测试独立门禁 |
| 研究记录 | 观察、假设、阻塞、决策的时间线与版本历史，区分开发证据与最终测试内容 |
| 汇报中心 | 论文精读 / 实验复盘 / 周进展三类叙事结构 → 离线 HTML（长页阅读或翻页演示），ZIP 整包交付 |

## 设计原则（护栏）

- **三集分离**：探索只依据验证集；测试集单独审批，其指标与派生结论不进入研究规划。
- **数据真实**：指标只能由原始 JSONL 日志重新解析；报告导出前再次校验内容哈希。
- **审批绑定**：审批绑定规格哈希、代码快照与远程环境快照，任一变更即失效；同一审批不重复开跑。
- **保守停机**：不自动重试；预算与停滞熔断持久化，重启不清零；异常区分「实现坏了」与「方法无效」。
- **诚实的隔离声明**：远端执行是协议级隔离（参数白名单、路径校验、SHA256 冻结）；Conda/venv 不是恶意代码沙箱。

## 快速开始

环境要求：Python ≥ 3.11，Node.js ≥ 20，macOS 或 Linux。

```bash
python3.11 -m venv .venv
.venv/bin/pip install -e '.[test]'
npm install
npm run build
npm start            # 打开 http://127.0.0.1:8775
```

开发模式（前端热更新，`/api` 代理到后端）：

```bash
npm start            # 终端一：后端 8775
npm run dev          # 终端二：前端 5173
```

首次使用可点击「体验教学示例」：示例数据均明确标注为合成内容，不构成科研结论。

## 测试

浏览器测试覆盖：互动精读 → 生成汇报 → 打开离线包；以及包迁移到新目录后在断网、关闭

## 项目结构

```text
backend/        FastAPI 服务：领域模型、证据存储（SQLite WAL+FTS5）、
                实验与批次、文献导入、报告导出、单进程调度编排
runner/         远程 GPU 固定执行器（仅标准库；随审批冻结版本，哈希部署）
apps/web/       React + TypeScript 科研工作台界面
packages/       离线 HTML 渲染器：MathJax 在生成阶段输出内联 SVG，页面无需联网
vendor/         外部 Skill 内容快照（summary-to-html）：素材契约、校验与打包脚本
.qoder/skills/  项目级 Skill：research-report-to-html 科研汇报工作流
tests/          pytest、渲染测试与 Playwright 浏览器测试
```

技术栈：FastAPI · Pydantic · SQLite · Paramiko · pdfplumber/pypdfium2 · React 19 · Vite · MathJax

## 数据与隐私

- 数据目录默认 `.research/`（可用环境变量 `RESEARCH_DATA` 指定），已被 `.gitignore` 排除。
- 服务仅绑定 `127.0.0.1`，请求需携带本地会话令牌并校验来源。
- arXiv / Crossref 检索与模型调用都需要逐项授权；模型密钥通过环境变量提供，不写入任何配置文件。
- 报告导出为自包含离线包（相对链接 + 内容哈希命名），不上传第三方。

## 当前状态与边界（诚实声明）

- 实验控制协议已用合成/桩任务验证：smoke 拦截、预算持久、断线对账、checkpoint 冻结、测试隔离。
- **尚未连接真实 GPU 训练与真实模型服务**；接入后需要重新做一轮端到端验收。
- 教学示例与合成日志在界面和报告中均有明确标记，避免与真实科研结果混淆。
- 需要强安全隔离时，请为远端执行配置独立账户与文件权限。
